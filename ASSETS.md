# Image Treatment

Photography should feel:
- architectural,
- residential,
- warm,
- natural,
- New Zealand-aware,
- premium without luxury excess.

Prefer:
- large crops,
- edge-to-edge imagery,
- asymmetric composition,
- architectural framing.

Avoid:
- rounded image cards everywhere,
- excessive overlays,
- dark gradient masks,
- blue/green eco colour grading,
- fake HDR,
- glowing solar panels,
- stock-photo effects,
- decorative image collages.

Do not apply the same aspect ratio to every image.

---

# Performance

Keep these files as source masters during initial implementation.

Before final delivery:
- create appropriately sized web derivatives,
- prefer WebP or AVIF where supported,
- preserve source masters,
- use responsive image sizing,
- lazy-load below-the-fold photography,
- avoid shipping full-resolution 14 MB imagery to visitors.

Do not destructively overwrite the source masters.

---

# Asset Rule

Photography supports the art direction.

It does not define the layout.

Do not redesign sections around the available stock images.

If an image does not work in the intended composition, change the crop or choose another asset rather than compromising the design system.
